# 메이플 캐릭터 관리 웹 — 설계안

기존 구글 시트(탭 20개)를 분석해 웹 페이지 구조로 옮기기 위한 설계 문서.

## 1. 기존 시트 분석

시트의 탭은 성격별로 7가지로 묶인다.

| 분류 | 탭 | 내용 | 데이터 형태 |
| --- | --- | --- | --- |
| **캐릭터 로스터** | 유니온&링크 | 48캐릭: 직업군·직업·유니온 효과·링크 효과·닉네임·육성 계획·레벨·비고·길드·카룻/스데/루윌슬 가능 여부·유니온 전투력 + 부위별 장비(얼장·눈장·귀고리·반지·뱃지·견장·목걸이·벨트·성배·카룻·네크로·블랙셋·앱솔) + 레벨 총합/유니온 레벨 수식 | 표(구조화) — 장비 칸은 `10성 9/0` 같은 자유 텍스트 |
| **캐릭터별 장비** | 소마/바이퍼/라라/엔버 장비창 | 장비 툴팁 스크린샷 모음, 바이퍼는 부위별 잠재 목표 메모 | 이미지 + 메모 |
| | 비숍 템세팅 | 목표 세팅: 부위 × (스타포스·윗잠·아랫잠·추옵·작·예상 가격) | 표(구조화) |
| **본캐(엔버) 성장 기록** | 엔버 환산 | 날짜별 환산 계산기 캡처 (예: 23/09/02 쌍크 장갑 구매 후 측정) | 날짜 + 이미지 |
| | 영수증... | 구매 기록: 날짜·상품명·비고·가격·한줄평 + 캡처 | 표 + 이미지 |
| | 사냥 | 사냥터·시간·몹 수·메소 | 단일 기록 |
| **공략 노트** | 엔버 무릉 | 층별 보스와 대응(버프·딜 순서), 시드링 효율 표 | 표 + 텍스트 |
| | 엔버 딜 사이클 (+사본) | 스킬별 쿨타임, 수로 단계별 스킬 순서 | 표 + 순서 리스트 |
| **계산기** | mvp작 | 캐시템 가격 → 경매장 가격 → 환산가 → 회수율 | 수식 |
| | mvp작 참고용 옥션 시세표 | 품목 × 세트 수량 × 날짜별 시세 | 시계열 |
| | 거래탭 | 현금 → 메소 → 솔 에르다 매매 이득 비율 | 수식 |
| | 연금술 / 장비제작 / 장신구 제작 | 2020년 제작 원가·수익 계산 | 수식 (현재 미사용으로 보임) |
| **할 일** | 강화 | 강화/세팅 TODO 메모 | 체크리스트 |
| **정리 대상** | 시트18, 엔버 장비창 (비어 있음), 딜 사이클 사본 (중복) | — | 이전 안 함 |

시트를 쓰면서 불편했을 지점:
- **장비 정보가 스크린샷과 자유 텍스트로 흩어져 있음** → 검색·비교·갱신이 어렵다.
- **같은 정보가 여러 곳에 중복됨** (엔버 장비: 장비창/환산/영수증 탭).
- **시세가 시점별로 칸이 늘어남** (`2023.07.24`, `2023.08.25` 열 추가) → 시계열 데이터가 표 구조에 억지로 들어가 있다.
- **수식이 깨져도 알기 어려움** (mvp작 `#DIV/0!` 다수).

## 2. 핵심 설계 방향

1. **캐릭터를 중심에 둔다.** 장비·목표 세팅·구매·환산 기록이 모두 캐릭터에 딸려 있도록 한다.
2. **넥슨 Open API로 자동화할 수 있는 건 자동화한다.** 레벨·직업·길드·장비·유니온·전투력은 API로 조회할 수 있어서, 장비창 스크린샷을 대부분 대체할 수 있다. 수동 입력은 API에 없는 정보(육성 계획, 메모, 목표 세팅, 구매가)만 받는다.
3. **기록은 시계열로 쌓는다.** 환산, 시세, 구매를 "날짜가 붙은 레코드"로 저장해 그래프와 이력으로 보여준다.
4. **계산기는 입력 폼 + 결과 패널** 구조로 만들고, 수식은 코드로 옮겨 오류를 막는다.

## 3. 페이지 구조 (IA)

```
/                       대시보드
/characters             캐릭터 목록 (유니온&링크 대체)
/characters/:name       캐릭터 상세
  ├─ 개요               기본정보·유니온/링크 효과·육성 계획·메모
  ├─ 장비               현재 장비 (API) + 수동 메모
  ├─ 목표 세팅          부위별 목표 vs 현재 (비숍 템세팅 형식)
  └─ 기록               환산·전투력 변화, 구매 내역, 사냥 기록
/purchases              전체 구매 내역 (영수증 탭)
/guides                 공략 노트 목록
/guides/:slug           무릉 층별 공략, 딜 사이클 등
/tools/cash-shop        캐시템 회수율 계산기 (mvp작)
/tools/sol-erda         현금·메소·솔 에르다 거래 계산기 (거래탭)
/prices                 경매장 시세 기록 (옥션 시세표)
/todo                   할 일 (강화 탭)
/archive                레거시 제작 계산기 (연금술·장비제작·장신구) — 선택
```

### 3.1 대시보드 `/`
- 요약 카드: 유니온 레벨, 레벨 총합, 본캐 전투력(최근 값과 변화량), 캐릭터 수.
- 최근 구매 5건, 미완료 할 일.
- 본캐 전투력/환산 추이 미니 그래프.

### 3.2 캐릭터 목록 `/characters`
- 시트의 유니온&링크 표를 그대로 옮기되, 필터와 정렬을 붙인다.
  - 필터: 직업군, 길드, 육성 계획(제로백·버닝·유챔 등), 카룻/스데 가능, 장비 세팅 여부.
  - 정렬: 레벨, 유니온 전투력.
- 컬럼 그룹: **기본**(직업·닉네임·레벨·길드) / **유니온·링크** / **보스**(카룻·스데·루윌슬) / **장비 요약**. 장비 13칸은 기본으로 접어 두고 토글로 펼친다.
- 하단 집계: 레벨 총합, 유니온 레벨(**상위 42캐릭 레벨 합**을 자동 계산, 시트의 `SMALL()` 빼기 수식을 대체).
- 모바일에서는 표 대신 카드 리스트로 보여준다.

### 3.3 캐릭터 상세 `/characters/:name`
- **개요**: API 기본정보(레벨·직업·길드·전투력·캐릭터 이미지) + 수동 필드(유니온 효과, 링크 효과, 육성 계획, 비고).
- **장비**: API 장비 정보를 부위 그리드(인게임 장비창 배치)로 표시하고, 부위를 누르면 스타포스·잠재·에디·추옵 툴팁을 띄운다. 부위별 메모(예: 바이퍼 `장갑: 9%/1줄, 10회`)를 붙일 수 있다. API로 조회되지 않는 캐릭터는 수동 입력이나 스크린샷 첨부로 대체한다.
- **목표 세팅**: 부위 × (스타포스·윗잠·아랫잠·추옵·작·예산) 표. 현재 장비(API)와 비교해 달성한 칸을 표시하고, 남은 예산 합계를 보여준다.
- **기록**: 날짜별 환산/전투력 스냅샷 타임라인 그래프, 구매 이벤트를 그래프에 마커로 표시해 "어떤 템을 사서 얼마나 올랐는지" 확인. 그 아래에 구매 내역과 사냥 기록.

### 3.4 공략 노트 `/guides`
- 마크다운 문서 + 전용 블록 두 종류:
  - **층별 표** (무릉): 층·보스·전략·비고.
  - **스킬 순서** (딜 사이클): 단계별 스킬 칩 나열, 스킬 쿨타임 표.
- 시드링 효율 같은 작은 표는 마크다운 표로 넣는다.

### 3.5 계산기 `/tools/*`
- **캐시템 회수율**: 품목·캐시 가격·마일리지 할인·경매장 시세 입력 → 환산가·회수율 계산. 시세는 `/prices`의 최신 값을 자동으로 불러온다.
- **솔 에르다 거래**: 투입 현금·환율(매수/매도)·수수료 3% 입력 → 이득 비율 비교(솔 에르다 경유 vs 직접).

### 3.6 시세 `/prices`
- 품목 × 세트 수량 단위로 날짜별 시세를 쌓는다. 품목별 최신가와 추이 그래프를 보여준다.

## 4. 데이터 모델

```ts
Character {
  id, name /* 닉네임, API 조회 키 */, jobGroup, job,
  unionEffect, linkEffect, plan /* 제로백·버닝·유챔… */,
  level, guild, note,
  boss: { karut: bool, stoneDesire: bool, lucidWillSlime: bool },
  unionPower?, isMain: bool, archived: bool
}
EquipNote     { characterId, slot, text }          // API 장비에 붙이는 메모, 혹은 API 없을 때 수동 장비
TargetSetup   { characterId, slot, item, starforce, mainPot, addPot, flame, scroll, budget }
StatSnapshot  { characterId, date, combatPower?, statScore? /* 환산 */, note, imageUrl? }
Purchase      { characterId?, date, itemName, detail, price /* 메소 */, comment, imageUrl? }
HuntLog       { characterId, date, map, minutes, kills, meso }
PriceQuote    { item, bundleSize, date, price }
Guide         { slug, title, characterId?, body /* markdown + 커스텀 블록 */ }
Todo          { characterId?, text, done, createdAt }
```

- 가격 단위는 **메소 정수**로 통일하고, 화면에서만 `억`·`만` 단위로 포맷한다. 시트에서는 `만 메소`, `억`이 섞여 있다.
- 장비 칸의 `10성 9/0` 같은 자유 텍스트는 이전할 때 원문을 `EquipNote.text`로 보존한다. 이후 API 데이터가 있는 캐릭터부터 구조화된 정보로 바꿔 간다.

## 5. 기술 구성 (권장)

| 영역 | 권장 | 이유 |
| --- | --- | --- |
| 프론트 | Vite + React + TypeScript | 정적 배포 가능, 표·그래프 라이브러리 풍부 |
| 표 | TanStack Table | 필터·정렬·컬럼 토글 |
| 그래프 | Recharts | 환산/시세 추이 |
| 저장소 | Supabase (Postgres + 이미지 스토리지) | PC·모바일 어디서나 같은 데이터, 스크린샷 보관 |
| 게임 데이터 | 넥슨 Open API (`open.api.nexon.com`) | 캐릭터 기본·장비·유니온·전투력 |
| API 키 보호 | Supabase Edge Function 같은 서버리스 프록시 | API 키를 브라우저에 노출하지 않기 위함 |
| 배포 | Vercel 또는 GitHub Pages | 무료 |

더 가볍게 시작하려면 저장소를 **JSON 파일 + localStorage**로 바꿀 수 있다. 다만 여러 기기에서 같은 데이터를 보려면 결국 DB가 필요하다.

## 6. 시트 → 웹 이전 방법

1. xlsx를 내려받아 변환 스크립트로 JSON을 만든다.
   - 유니온&링크 → `Character` + `EquipNote`
   - 영수증 → `Purchase`, 엔버 환산 → `StatSnapshot`(이미지 첨부)
   - 옥션 시세표 → `PriceQuote` (가로 날짜 열을 행으로 펼침)
   - 무릉·딜 사이클 → `Guide` 마크다운
   - 비숍 템세팅 → `TargetSetup`
2. 시트에 들어 있는 이미지 107장을 추출해 스토리지에 올리고, 레코드의 `imageUrl`에 연결한다.
3. 빈 탭(시트18, 엔버 장비창)과 사본(딜 사이클 사본)은 이전하지 않는다. 사본에만 있는 평딜/극딜 메모는 원본 공략에 합친다.

## 7. 구현 단계

| 단계 | 범위 |
| --- | --- |
| 1 | 프로젝트 세팅, 캐릭터 목록/상세(수동 데이터), 시트 데이터 이전 |
| 2 | 넥슨 Open API 연동 (기본정보·장비·전투력 자동 갱신) |
| 3 | 기록: 구매 내역, 환산/전투력 타임라인 그래프 |
| 4 | 목표 세팅 vs 현재 장비 비교 |
| 5 | 계산기, 시세, 공략 노트, 할 일 |
| 6 | 대시보드, 모바일 최적화 |

## 8. 결정이 필요한 것

- 데이터 저장: Supabase(여러 기기 동기화) vs 로컬 JSON(간단).
- 레거시 제작 계산기(연금술·장비제작·장신구, 2020년 시세)를 아카이브로 남길지, 버릴지.
- 공개 범위: 혼자만 볼지(로그인 필요), 링크 공유를 허용할지.
