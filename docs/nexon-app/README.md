## 서비스 소개

메이플스토리 캐릭터·장비·강화 기록을 한 곳에서 정리하는 개인용 캐릭터 노트입니다.
보유 캐릭터의 레벨, 전투력, 장착 장비와 유니온 레벨을 매일 갱신해 보여주고,
스타포스·큐브·잠재능력 재설정 기록을 장비별로 모아 강화에 들인 횟수를 확인할 수 있습니다.

## API 활용 목적

본인 계정 캐릭터들의 정보를 하루 한 번 조회해 정적 웹 페이지로 보여주기 위해 사용합니다.

- 사용 API: 캐릭터 식별자(ocid) 조회, 캐릭터 기본 정보, 종합 능력치(전투력), 장착 장비 정보, 유니온 정보,
  스타포스 강화 결과, 큐브 사용 결과, 잠재능력 재설정 이용 결과
- 호출 방식: 서버(GitHub Actions)에서 하루 1회 일괄 조회해 결과를 정적 페이지로 배포합니다.
  방문자 브라우저에서는 API 를 직접 호출하지 않으며, API Key 는 서버 비밀값으로만 보관합니다.
- 서비스 단계가 필요한 이유: 최근 2년치 강화 기록을 하루 단위로 조회해야 해서 개발 단계 한도(하루 1,000건)로는
  캐릭터 정보 갱신과 기록 수집을 함께 하기 어렵습니다.
- 데이터 이용: 영리 목적으로 쓰지 않으며, 페이지 하단에 "Data based on NEXON Open API" 를 표기합니다.
