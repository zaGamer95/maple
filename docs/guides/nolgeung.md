# 놀긍(놀라운 긍정의 혼돈 주문서 100%) 판단 (2026-11-13)

## 사실
- 메소샵 4,500만 메소, 월드당 100개, 2026-11-19 02:00까지. 교환 불가 장비에만 사용.
- 장비가 가진 공격력·STR·DEX·INT·LUK·방어력·이동속도·점프력·최대 HP/MP가 **각각 따로** 아래 확률로 오른다 (내려가지 않음).
  +6 5.93% · +4 4.94% · +3 13.87% · +2 23.87% · +1 33.01% · +0 18.38% (+5는 없음). 최대 HP·MP는 10배.
- 한 작 기대값: 스탯마다 **+1.78**.
- 리턴 스크롤: 2026-09-17 개편 후 주문서 강화 UI에서 **4억 메소**. 1회 한정으로 주문서 쓰기 전 상태로 되돌림. 교환 불가 장비만.
- 메소 탭 주문서에는 주흔 피버 타임·썬데이 주흔 할인이 안 붙는다. 썬데이 반값은 주문의 흔적 작에만 해당.

## 놀긍리턴작 (공 6 나올 때까지 리턴)
- 시도 1번 = 놀긍 0.45억 + 리턴 4억 = 4.45억.
- 공 +6 확률 5.93% → 평균 16.9번 → **슬롯 하나에 약 75억**. 공 +4 이상에서 멈춰도 약 41억.
- 평균(+1.78)보다 공 약 4 더 얻자고 75억은 안 맞는다 → **하지 않는다**.

## 그냥 놀긍 (리턴 없이)
- 슬롯 하나 0.45억에 공 +1.78 · 주스탯 +1.78 · 부스탯 +1.78 (기대값). 공 1 = 주스탯 4로 치면 주스탯 약 9 상당.
- 방어구 주흔작은 성공 시 주스탯 +3(100%) · +4(70%) · +7(30%, 실패하면 슬롯 소모). 기대값 주스탯 3 안팎.
- 스타포스로 공격력이 붙은 방어구라면 놀긍이 주흔보다 슬롯당 2~3배 낫다.

## 사용자 방식 (2026-11-13 정정)
- 리턴작이 아니라 "첫작만 놀긍 → 공 6이 아니면 스타포스 유지 이노센트로 초기화 → 다시 첫작"을 하던 방식.
- 스타포스 유지 이노센트가 지금 코인샵에 없어서 이번에는 렌 방어구를 썬데이(주흔 반값)에 주흔 15%작으로 진행 예정.
- 금~일 피버 타임에 15% 주문서는 손재주 Lv.1 기준 25%. 실패하면 업그레이드 횟수가 차감되고 순백의 주문서로 복구 (100%짜리는 1회 복구, 5%짜리는 주흔 2,000개로 제작).

## 공식 공지로 다시 확인 (2026-11-13)
- 2026-09-17 주문서 강화 개편: 강화 UI 메소 탭에 놀긍 100% 3억 메소(이벤트 메소샵은 4,500만), 리턴 4억. 장갑 전용으로 쓸 메소 주문서는 없다 (악세서리·귀장식·매지컬 무기·펫장비만). 메소 탭 주문서는 피버·썬데이 할인 대상이 아니다.
- 2023-04-20 업데이트: 주흔 강화에 순백 100% (주흔 20,000) · 이노센트 100% (12,000) · 아크 이노센트 100% (24,000, 스타포스 유지) · 방어구·장갑 15% 추가. 2026 개편 전용 탭 목록에도 순백·이노센트·아크 이노센트가 있음 → 지금 주흔 가격은 인게임 UI로 확인 필요. 황금 망치는 사용자 확인으로 지금 없음.
- 주흔 시세 2026-11-13: 최저 개당 3,300 (7일 평균 2,777), 오르는 중. 보유 20만 장 이상.

## 15%작 주흔 시뮬 (순백으로 매번 복구, 성공할 때까지)
- 성공 1작당 주흔 = (1/p) × 1회 비용 + (1/p − 1) × 순백 20,000. 순백이 95% 이상을 차지한다.
- 썬데이(피버 25% + 반값): 성공 1작당 약 3.1만 장 (메소 약 1억) → 20만 장으로 약 6작.
- 정가 피버: 약 6.2만 장, 평일 정가: 약 11.7만 장.
- 1회 비용(455~700장)과 순백 가격이 지금도 같은지는 UI에서 확인해야 한다.

## 업그레이드 횟수 1회 복구 비용 비교 (2026-11-13 시세, 주흔 개당 3,300)
| 방법 | 1회 복구 기대 비용 |
|---|---|
| 경매장 순백 5% (개당 130만) | 약 2,600만 (평균 20장) |
| 주흔 순백 100% 썬데이 반값 (10,000개) | 약 3,300만 |
| 경매장 순백 10% (개당 340만) | 약 3,400만 (평균 10장) |
| 주흔 순백 100% 정가 (20,000개) | 약 6,600만 |
- 순백 5%·10%는 실패해도 주문서만 사라지고 장비는 그대로. 손재주·길드 스킬 확률 보너스가 붙으면 더 싸진다 (미확인).
- 썬데이 15% 성공 1작 (시도 4회 + 복구 3회): 경매장 5%로 복구하면 약 8,300만, 주흔 순백이면 약 1억 400만. 주흔은 시도 비용에만 쓰고 복구는 경매장 5%가 싸다.
- 아크 이노센트 24,000개 확인 (썬데이 반값이면 12,000개 = 약 4,000만).
