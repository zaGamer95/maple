# VIP 부스터 vs HEXA 부스터

조사일 2026-10-18. 공식 가이드·공지와 커뮤니티 정리를 합친 내용이고, 실측은 자그3 사냥 기록 기준.

## 공통 효과
- 더블클릭하면 많은 경험치를 주는 **불꽃 몬스터**가 100초 동안 소환된다 (2026년 6월 공식 사과 보상 공지 문구 기준).
- 다른 맵으로 이동하면 효과가 사라진다.
- 커뮤니티 정리(나무위키, 아카라이브)는 두 아이템의 성능이 같다고 본다. 공식 문서에서 성능을 직접 비교한 문구는 찾지 못했다.
- 동시에 겹쳐 쓸 수 있는지는 확인하지 못했다 (커뮤니티 질문만 있고 확실한 답 없음).

## 차이

| | VIP 부스터 | HEXA 부스터 |
|---|---|---|
| 얻는 곳 | 이벤트·보상 지급 (신규 용병 지원, 사과 보상 등) | HEXA 매트릭스 [솔 에르다 반환]: 솔 에르다 1개 → HEXA 부스터 1개 (공식 가이드) |
| 하루 사용 제한 | 예전에는 하루 10회. 최신 정리에는 제한이 없어졌다는 내용과 10회라는 답변이 섞여 있음 → 게임 내 툴팁으로 확인 필요 | 제한 없음 (2024-12 테스트 서버 확인 글, 나무위키) |
| 비용 | 받은 만큼만 사용 | 솔 에르다 1개를 쓴다. 솔 에르다 1개는 희미한 솔 에르다의 기운 30개로도 바꿀 수 있어서 그만큼의 기회비용이 있음 |

## 자그3 실측 (2026-10-18, 밤길3, 일반 50% 추경 + 일반 룬 = 추가 경험치 718%)
- 1회차: 1분 46초, 723마리, 985억 8659만
- 2회차: 2분 3초, 831마리, 1510억 7524만 (트레저 헌터 레어 폴로 452억 포함)
- 같은 조건에서 일반몹 마리당 약 1억 453만으로 잡으면, 부스터로 늘어난 경험치는 **한 번에 약 190억~230억**이다.
  마리당 경험치로는 평소의 1.2~1.3배.
- HEXA 부스터로 쓸지는 "솔 에르다 1개 ↔ 부스터 1회(약 200억)"로 비교하면 된다.
